# eCommerce Application

A fullstack eCommerce application built with Spring Boot and Angular.

## Technologies Used

### Backend
- Spring Boot
- Java

### Frontend
- Angular
- TypeScript

## Getting Started

### Prerequisites
- Java JDK
- Node.js and npm
- Maven

### Installation

1. Clone the repository
```bash
git clone https://github.com/Simbadonkey/ecommerce.git
cd ecommerce
```

2. Backend Setup
```bash
cd backend
mvn clean install
mvn spring-boot:run
```

3. Frontend Setup
```bash
cd frontend
npm install
ng serve
```
